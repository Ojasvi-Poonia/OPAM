## Installation

### Quick Start (Recommended)

```bash
# Clone repository
git clone https://github.com/yourusername/opam.git
cd opam

# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements-minimal.txt

# Run dashboard
streamlit run opam_dashboard_fixed.py
```

### Full Features (includes deep learning)

```bash
pip install -r requirements.txt
```

See [REQUIREMENTS_README.md](REQUIREMENTS_README.md) for detailed installation instructions.

## Requirements

- Python 3.11+ (3.12 recommended)
- See requirements-minimal.txt for core dependencies
- See requirements.txt for full features
